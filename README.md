## 🔍 Troubleshooting

### The app will not open
- Check that the file finished downloading.
- Unzip the folder if needed.
- Try running the app again.
- Right-click the file and choose Run as administrator.

### The webcam does not work
- Close other apps that use the camera.
- Check Windows camera permissions.
- Plug in an external webcam again if you use one.
- Restart the app.

### Chat is slow
- Close other large apps.
- Make sure your local model is ready.
- Wait for the first load to finish.
- Restart the app if it freezes.

### The app looks empty
- Reload the page or restart the app.
- Wait for local files to finish loading.
- Check that the model folders are in place.
